# AutoInsight —— 汽车行业数据分析与智能决策平台

AutoInsight 是一个面向汽车行业的数据分析与智能决策平台，集成汽车市场数据、车型信息、销量分析、销量预测、购车推荐以及用户舆情分析等功能。

项目采用前后端分离架构，包含：

- **Vue 3 + TypeScript** 构建的前端可视化系统
- **FastAPI + SQLAlchemy** 构建的后端服务
- **MySQL / SQLite** 数据库
- **汽车行业数据集**
- **数据分析、预测、推荐与舆情分析功能**

项目主要用于汽车行业数据分析、课程设计及相关 Web 全栈应用实践。

## 一、项目简介

随着汽车市场车型数量和用户评价数据不断增加，传统的信息查询方式难以直观地反映汽车市场的整体变化。

AutoInsight 通过对汽车品牌、车型、销量、能源类型、区域市场以及用户评价等数据进行整理和分析，将复杂的汽车行业数据转化为可视化信息，并结合销量预测、购车推荐和舆情分析，为用户提供更加直观的数据分析与辅助决策功能。

系统主要包含以下功能：

- 用户登录与权限管理
- 汽车行业数据驾驶舱
- 汽车品牌与车型信息
- 汽车市场分析
- 汽车销量分析
- 销量趋势预测
- 智能购车推荐
- 用户评价与舆情分析
- 用户、订单、库存及操作日志管理

## 二、系统架构

项目采用前后端分离架构：

```text
                         AutoInsight
                              │
                ┌─────────────┴─────────────┐
                │                           │
             前端系统                    后端服务
                │                           │
        Vue 3 + TypeScript              FastAPI
        Vite + Pinia                    SQLAlchemy
        Vue Router                      JWT
        Axios                           Pydantic
        ECharts                              │
                │                           │
                └─────────────┬─────────────┘
                              │
                              ▼
                       MySQL / SQLite
                              │
                              ▼
                         数据集 / 数据库
```

**前端负责：**

- 页面展示
- 数据可视化
- 用户交互
- 路由管理
- 登录状态管理
- API 请求

**后端负责：**

- API 服务
- 用户认证
- 权限控制
- 数据库操作
- 数据分析
- 销量预测
- 购车推荐
- 舆情分析

## 五、系统功能

### 5.1 用户认证

系统提供用户登录及身份认证功能。

主要功能：

- 用户登录
- JWT Token 认证
- 密码加密
- 用户角色管理
- 权限控制
- 未登录状态处理

系统根据用户角色提供不同的数据访问和管理权限。

### 5.2 数据驾驶舱

数据驾驶舱用于展示汽车行业核心指标，并通过图表对市场数据进行可视化。

主要包括：

- 汽车销量概览
- 品牌销量排行
- 能源类型市场分布
- 区域市场分析
- 月度销量趋势
- 市场核心指标

通过可视化图表帮助用户快速了解汽车市场整体情况。

### 5.3 汽车品牌与车型

系统提供汽车品牌及车型相关信息查询。

主要数据包括：

- 品牌
- 车型
- 价格
- 能源类型
- 续航
- 电池容量
- 动力参数
- 车型评分
- 销量

后端数据模型包含品牌、车型、销量、评价、预测、库存和订单等业务数据。

### 5.4 市场分析

系统支持从多个维度分析汽车市场：

- 品牌维度
- 能源类型维度
- 区域维度
- 月度销量维度
- 市场趋势
- 市场结构

用户可以通过不同的筛选条件查看汽车市场变化。

### 5.5 销量分析与预测

系统提供汽车销量数据分析以及未来销量预测功能。

销量预测主要基于：

```text
历史销量数据
      ↓
近 6 个月趋势分析
      ↓
季节因素
      ↓
预测计算
      ↓
预测结果
      ↓
置信区间
```

对于已经导入的真实模型预测数据，系统优先使用数据库中的预测结果；没有对应真实预测数据时，再使用在线算法进行预测。

预测结果会进行持久化保存，便于后续查询和展示。

### 5.6 智能购车推荐

系统根据用户输入的购车需求，对符合条件的车型进行综合评分和排序。

推荐流程：

```text
用户购车需求
      ↓
预算 / 能源类型等硬约束
      ↓
车型过滤
      ↓
价格 / 续航 / 使用场景等多维度评分
      ↓
根据用户关注因素进行加权
      ↓
推荐车型
```

推荐算法会根据预算、能源类型、使用场景及用户关注因素等条件，对车型进行综合评分，并生成推荐结果。

### 5.7 舆情分析

系统对汽车用户评价进行统计和情感分析。

主要功能：

- 用户评价展示
- 正负面情感分析
- 情感趋势
- 高频关键词
- 品牌口碑分析
- 用户评价统计

评价数据与情感分析结果进行关联，可以进一步分析不同品牌和车型的用户口碑。

### 5.8 后台管理

系统提供后台管理功能，包括：

- 用户管理
- 订单管理
- 库存管理
- 操作日志
- 数据分析
- 系统管理

不同角色拥有不同的系统权限。

## 九、启动后端

进入后端目录：

```bash
cd backend
```

创建 Python 虚拟环境：

```bash
python -m venv .venv
```

Windows 激活虚拟环境：

```bash
.venv\Scripts\activate
```

安装依赖：

```bash
pip install -r requirements.txt
```

### 9.1 配置环境变量

复制 `.env.example` 为 `.env`：

```bash
cp .env.example .env
```

根据实际环境修改配置。

本地没有 MySQL 时，可以使用 SQLite：

```text
DATABASE_URL=sqlite:///./car2026.db
```

生产环境需要使用独立的数据库配置，并更换 `SECRET_KEY`。

### 9.2 初始化数据库

使用真实数据：

```bash
python scripts/import_real_data.py --fresh
```

或者生成演示数据：

```bash
python scripts/seed_demo.py
```

### 9.3 启动 FastAPI

```bash
python -m uvicorn app.main:app --reload --port 8000
```

后端启动后：

- `http://localhost:8000`
- Swagger API 文档：`http://localhost:8000/docs`

## 十一、前后端连接

前端支持 Mock 数据和真实后端两种运行方式。

### 使用 Mock 数据

```text
VITE_USE_MOCK=true
```

这种方式不需要启动后端即可进行前端页面开发和演示。

### 使用真实后端

修改前端环境变量：

```text
VITE_USE_MOCK=false
VITE_API_BASE_URL=/api
```

前端请求 `/api/...` 会通过 Vite 代理转发到 `http://127.0.0.1:8000`。

整体请求流程：

```text
浏览器
  │
  ▼
Vue 3 前端
  │
  │ /api
  ▼
Vite Proxy
  │
  ▼
FastAPI
  │
  ▼
SQLAlchemy
  │
  ▼
MySQL / SQLite
```

前后端 API 路由和数据字段按照统一接口契约进行对接，后端 API 使用驼峰格式输出字段。
